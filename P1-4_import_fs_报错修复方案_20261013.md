## 一、问题根因

### 实测证据（2026-10-12 15:xx）

**症状 1: TS2792 红鲱鱼**
```typescript

// 编译器报错：
// TS2792: Cannot find module 'fs'. Did you mean to set the 'moduleResolution' option to 'nodenext'?
```

**症状 2: 运行时矛盾**
```javascript
// 同一会话中检查
typeof process === "object"  // true
typeof Deno === "object"     // true (Deno runtime 存在)
typeof require === "function" // undefined (Node.js require 不存在)
typeof fetch === "function"   // true (Deno fetch 存在)
```

**根因分析**:
1. **编译期**: 内嵌 Deno TS compiler 使用默认 `moduleResolution`，对 Node.js 内置模块报 TS2792
2. **运行时**: Deno sandbox 提供 `process`/`Deno` 全局对象，但不提供 Node.js `require()` 和内置模块
3. **脱节**: 编译期建议改 `nodenext`，但运行层根本没有 Node.js 模块系统

**影响**: 
- 用户被误导去改 tsconfig（无效）
- 错误提示不清晰（TS2792 是通用错误，未说明沙箱限制）
- 用户体验差（以为是自己配置问题）

// 同时在诊断管道拦截特定错误码
fn intercept_diagnostic(diag: &Diagnostic) -> Option<Diagnostic> {
    match diag.code {
        2792 => {  // TS2792: Cannot find module
            let module_name = extract_module_name(diag);
            if is_node_builtin_module(module_name) {
                return Some(Diagnostic {
                    code: CUSTOM_ERROR_CODE,
                    message: format!(
                        "Node.js built-in module '{}' is disabled in Code Mode sandbox. \
                         Please use list_functions() registered SDK instead.",
                        module_name
                    ),
                    severity: Severity::Error,
                });
            }
        },
        2307 => {  // TS2307: Cannot find module or its type declarations
            // 同样处理
        },
        _ => {}
    }
    None
}

fn is_node_builtin_module(name: &str) -> bool {
    let deny_list = [
        "fs", "path", "http", "https", "net", "tls", "crypto",
        "child_process", "cluster", "dgram", "dns", "os", "readline",
        "stream", "tty", "url", "util", "v8", "vm", "zlib",
        "assert", "buffer", "console", "constants", "events",
        "module", "process", "punycode", "querystring", "string_decoder",
        "sys", "timers", "trace_events", "worker_threads",
    ];
    
    // 支持 node: 前缀
    let clean_name = name.strip_prefix("node:").unwrap_or(name);
    deny_list.contains(&clean_name)
}

fn register_denylist_hook(deny_list: &[&str]) {
    // Deno 的 ModuleLoader trait
    struct SandboxModuleLoader {
        base_loader: DefaultModuleLoader,
        deny_list: HashSet<String>,
    }
    
    impl ModuleLoader for SandboxModuleLoader {
        fn resolve(
            &self,
            specifier: &str,
            referrer: &str,
            kind: ResolutionKind,
        ) -> Result<ModuleSpecifier, AnyError> {
            let clean_specifier = specifier.strip_prefix("node:").unwrap_or(specifier);
            
            if self.deny_list.contains(clean_specifier) {
                return Err(anyhow::anyhow!(
                    "Code Mode sandbox denies Node.js built-in module '{}'. \
                     Use list_functions() registered SDK instead.",
                    clean_specifier
                ));
            }
            
            self.base_loader.resolve(specifier, referrer, kind)
        }
        
        fn load(
            &self,
            module_specifier: &ModuleSpecifier,
            maybe_referrer: Option<&ModuleSpecifier>,
            is_dyn_import: bool,
        ) -> Pin<Box<ModuleSourceFuture>> {
            // 同样检查
            // ...
        }
    }
    
    // 注册到 Deno runtime
    deno_runtime.set_module_loader(Box::new(SandboxModuleLoader {
        base_loader: DefaultModuleLoader::new(),
        deny_list: deny_list.iter().map(|s| s.to_string()).collect(),
    }));
}

// 对 process/Deno 做只读包装防绕过
fn protect_globals(runtime: &mut JsRuntime) {
