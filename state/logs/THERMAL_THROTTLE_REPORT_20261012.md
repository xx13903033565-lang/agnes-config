## ⚠️ 待爸确认事项

### 🌡️ 硬件侧排查（需手动检查）

#### 硅脂状态
- **症状**：如果设备使用超过 2 年，硅脂可能干裂失效
- **建议**：拆机检查 CPU 散热片接触面，重新涂抹导热硅脂
- **成本**：硅脂约 50-100 元，手工费 200-300 元

#### 散热鳍片积灰
- **症状**：风扇噪音大但出风量小
- **建议**：用压缩空气清理散热鳍片和风扇叶片
- **频率**：每 6-12 个月一次

#### VC 均热板老化
- **症状**：局部热点明显，散热不均匀
- **检测**：红外测温仪扫描机身表面温度分布
- **处理**：如老化严重需更换整个散热模组（成本较高）

## 📊 长期方案评估

### 方案 A：应用层限流（✅ 已实施）
**优点**：
- 无需改动硬件
- 可根据温度动态调整
- 成本低，立即可见效

**缺点**：
- 多任务处理速度下降
- 治标不治本

**适用场景**：短期应急，硬件不便维修时

---

### 方案 B：硬件升级
**选项 1：外接散热底座**
- 成本：200-500 元
- 效果：降低 5-10°C
- 优点：即插即用，无需拆机

**选项 2：内部散热改造**
- 重涂硅脂：+10-15°C 余量
- 清理积灰：+5-8°C
- 更换高效散热模组：+15-20°C（成本高，风险大）

**适用场景**：设备老旧，散热系统确实老化

---

### 方案 C：架构优化（推荐中长期）
**在 AgnesCode 层面做"并发任务限流 + 温度感知降级"**

#### 设计要点
1. **任务队列优先级调度**
   - 高优先级任务独占资源
   - 低优先级任务排队等待

2. **温度传感器集成**
   - 直接读取 SMC 传感器（需授权）
   - 或使用 powermetrics 实时监控

3. **动态并发池**
   ```python
   if temp > 80°C:
       max_workers = 2
   elif temp > 75°C:
       max_workers = 5
   else:
       max_workers = 10
   ```

4. **任务批处理**
   - 将多个小任务合并为一趟 LLM 调用
   - 减少往返次数（当前平均 14 趟/场）

**预计工作量**：2-3 天开发 + 1 天测试  
**预期效果**：同等性能下温度降低 10-15°C

## ⚙️ 技术细节

### 温度读取方法（按优先级）
1. **powermetrics**（需要 sudo，最准确）
2. **SMC 传感器**（ioreg 读取 TCXc/TCDc）
3. **CPU 使用率估算**（兜底方案，当前使用此方法）

### 并发数修改方式
- 直接修改 `~/.agnes/config/config.yaml`
- 键名：`AGNES_MAX_CONCURRENT_TASKS`
- 生效方式：下次任务调度时自动读取新值

### 退码说明
- `0`：成功
- `2`：用法错误或未授权
- `4`：温度读取失败
- `6`：权限不够
