# 老规矩 · 落地门槛

> 2026-10-09 老板令：落地程度必须到 90% 才能动手，不懂先去学。
> 本 skill 补充 `~/.dsh/AGENTS.md` 七步流程 + `~/泓记/AGENTS.md` 铁律，适用于 agnes 侧。

## 核心规则

**动手前自查（7 步老规矩）**：
①搭框架 → ②查泓记/NAS 有无现成 → ③没有就出去搜 → ④准确汇报 → ⑤爸批准 → ⑥更新笔记进泓记 → ⑦做不懂不钻牛角尖，循环回①

**90% 落地门槛（新增）**：
- 方案调研、脚本、数据、配置、测试**全部就绪**后才可动手部署
- 落地完成度 < 90% ⇒ 不动手、不部署、不声称"已落地"
- 剩余 < 10% 若涉及**用户无法代操作**（如 TCC 权限、需要用户终端命令）⇒ 明确告知那 10% 是什么，给出一条可执行的命令
- 落地完成度 ≥ 90% 且有用户确认/批准 ⇒ 立即执行剩余步骤

## 省 token 铁律（每次会话必守）
1. 窗口按任务边界换，不按困难换
2. 汇报写短（结论+证据+待办三行）
3. 失败 2 次就停手
4. 长会话退化 → 该换窗不是该告急

## 失败处理
- 同一操作试 2 次不成 ⇒ 停手、记入记忆（`feedback` 类型）、换思路或上报
- 不懂/不确定的事 ⇒ 先查泓记 → 再查外部 → 学透再动手（不硬钻、不空转）
