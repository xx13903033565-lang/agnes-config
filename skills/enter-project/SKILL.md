# enter-project — 进入项目即读该项目的实时记忆正本（只读，脚本闭环）

## 这颗技能在说什么（白话）

爸在 Qoder 里给每个店铺/文件夹都攒了一套「家规笔记」（记忆文件）。爱思办公进项目时要把这套笔记读进来，
才知道这店的规矩、踩过的坑、定过的价。
以前这颗技能读的是一份**拷贝出来的旧备份**（最后改动 2026-08-22，已经七周多没更新）——
读了它会拿旧规矩办事，比不读更坏。
现在改成**直接读实时正本**：正本在哪、有几颗、最新一颗什么时候改的，全部由同目录的
`qoder_memory_index.py` 当场扫盘报数，本文件里不写死任何项目清单或条数。

## 数据源（正本，只读）

- 各项目实时记忆正本根目录：`~/.qoder-cn/projects/<编码>/memory/`
- 全局（跨项目）实时记忆：`~/.qoder-cn/memory/`
- ⛔ 再读 `~/泓记/30_资源/Qoder记忆备份/`（那是 2026-08-22 的快照，只作历史留底，不作当前依据）

## 工具（这颗技能的入口，⛔用自然语言自己找路径）

`python3 ~/.agnes/skills/enter-project/qoder_memory_index.py <动作> [参数]`

| 动作 | 干什么 | 什么时候用 |
| --- | --- | --- |
| `list` | 现扫全量名册：真实路径 / 记忆颗数 / 最新改动 / 编码目录 | 想知道总共有哪些店有记忆、新不新 |
| `resolve <工作区路径或关键词>` | 把真实路径解析成那颗记忆正本目录 | 进项目第一步 |
| `show <工作区路径或关键词>` | 解析 + 打印该项目的 `MEMORY.md` 索引正文 | 进项目第二步（先读索引，别急着读全部） |
| `file <工作区路径或关键词> <记忆文件名>` | 打印单颗记忆文件全文 | 索引里点到哪颗、这活用到哪颗 |
| `check [--workspace <路径>]` | 自测腿：正例＋负控，全绿退 0 | 怀疑工具本身坏了 / 改完工具必跑 |

退码口径：`0` 解析成功；`2` 正本里没对上这个名（⛔当成「这店没记忆」以外的意思）；
`3` 命中多颗、要人挑（脚本会把候选全列出来，⛔它替我猜一棵）。

## 触发

用户说「进入X项目 / 打开X / 继续X / 看X店」，或当前工作目录落在某项目路径下 → 自动执行「进入」。

## ACTION: 进入（默认）

1. 定项目根 = 用户指定的路径，或当前工作目录。**拿绝对路径去 resolve，⛔自己按编码规则反推目录名**
   （现版编码把中文压成连字符，不同路径会撞成同一个名，反推必错）。
2. `.../qoder_memory_index.py resolve "<绝对路径>"` → 拿到记忆正本目录；脚本若退 3，把候选念给爸挑。
3. `.../qoder_memory_index.py show "<绝对路径>"` → 读索引；按索引里的钩子，只对**这活真用到的那几颗**
   跑 `file` 展开全文。
4. 汇总一句白话：「已加载 <项目名> 的记忆正本：N 颗，最新改动 <日期>」（数字只抄脚本印出来的，⛔手打）。
5. 若脚本退 2（该项目没有记忆正本）→ 白话说「这棵树还没攒过独立记忆」，再读全局那本
   `~/.qoder-cn/memory/MEMORY.md` 兜底；⛔拿旧备份充数、⛔假装读过。

## 隔离铁律（读侧）

- 只读**这一棵**工作区解析出来的正本目录，⛔跨项目搜、⛔把别店的规矩当本店的用。
- 脚本会打「⚠ 共用提醒」：编码撞车时，一个正本目录里混着几棵树的记忆（有几颗共用，`list` 那张表现扫现报，⛔写死在本文件里）。
  见到这行，逐颗按文件里写的工作路径认领；认不出来源的只当参考，⛔当本店家规执行。

## 写侧（边界，诚实说明）

- 爱思办公自己的记忆走它自家那套（`~/.agnes/memories/`），**不写** Qoder 的正本，也不写 `~/泓记`。
- 要沉淀新教训：写到当前工作区的笔记件里，末尾照实提示「新记忆已暂存工作区，还没进任何记忆正本」。
- ⛔ 假装已写入正本、⛔ 改动 `~/.qoder-cn/` 下任何东西（那本规矩由 Qoder 自己维护）。

## 省 token（老规矩）

先读索引再按需展开；条数多时只列标题＋一行钩子，单轮最多展开 10 颗全文；
能短不长篇；同一条命令失败 2 次就停手，别原地硬重试。

## 这颗技能怎么算修好了（验收口径）

在新窗里让它读一颗指定路径的记忆文件，它念回来的**首行内容对得上盘上原件**，
且报的**最新改动日期＝今天**（脚本现扫，⛔我替它镀个日期）。
